# Medical knowledge ingestion

Medical condition records, risk rules, monitoring guidance and patient-facing education belong here only after the source is verified and rights are checked.

Each record should include a stable ID, clinical topic, target population, author/reviewer, review date, cited source with DOI/URL, version, evidence limitations, and validation status.

**Current status: not populated.** An earlier prototype's claimed condition count is not accepted as a verified count in this new repository. Avoid fabricated protocols, automated diagnosis claims, and unreviewed emergency dosing guidance.

Planned schemas: condition catalog, symptom taxonomy, observation-to-action rules, human escalation guidance and follow-up criteria.
