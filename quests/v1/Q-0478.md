# Q-0478 — NASA-source Hackathon Demo, real historical data only

## Owner request
From native Portal add a visible **Demo for Hackathon** entry, an explicit source-and-limitations briefing, then a usable replay/dashboard of actual numerical NASA research values, with source pages and unknown indicators clearly differentiated. No fake human vitals, invented ECG curves, clinical risk judgements, identity collisions, or import into the authenticated store. Preserve both Vietnamese and English.

## Grounded source boundary
- NASA **Mercury-Atlas 7 Postlaunch Memorandum Report**, NASA Manned Spacecraft Center, June 15, 1962; unclassified archival NASA.gov copy at https://www.nasa.gov/wp-content/uploads/2026/01/ma07-te2.pdf
- Exact source sections and tables: p. 7-41 medical findings; p. 7-42 laboratory values; p. 7-33 flight-phase physiological summaries; p. 7-44 inflight BP recording quality; 7-45 BP summary.
- NASA OSDR OSD-569 (CBC) and OSD-575 (CMP/cytokines) are a *separate* Inspiration4 study source, NOT this 1962 Mercury dataset. Their numeric values cannot be added without actually importing OSDR measurement files.
- Challenge organizers did not provide one public synchronized all-metrics live astronaut sensor dataset. Missing SpO2, ECG waveforms, sleep, mood, glucose, dose data must remain **NOT_AVAILABLE**, not backfilled.

## Acceptance
1. User can start native offline demo from Portal without server/auth, observe provenance before replay.
2. Historical actual phase values are loaded from one versioned local JSON artifact, never medical patient stores.
3. Category and timestamp/timepoint remain original; aggregate means are labelled means, not live measurements.
4. Bilingual VI/EN and themed native Qt UI, accessible controls, no 3D/EKG misrepresentation.
5. Independent Windows/PySide6 reviewer required for final DONE, focused source-data inspection and payload check before component-ready.
